
<h1>☕ java-backend-3k2</h1>

<p><strong>Java - POO - Maven - JPA/Hibernate - Spring - Keycloak</strong></p>

<p>Repositorio con actividades prácticas, parciales y ejemplos integradores. Abarca desde conceptos básicos de sintaxis Java hasta la implementación de una arquitectura moderna con microservicios, API Gateway y OAuth 2.0 con Keycloak.</p>

<hr />

<h2>Contenido del repositorio</h2>

<p>El material está organizado en carpetas que cubren los siguientes tópicos:</p>

<ul>
<li><strong>Java Base</strong> - Sintaxis, estructuras de control, manejo de archivos CSV.</li>
<li><strong>Programación Orientada a Objetos (POO)</strong> - Herencia, polimorfismo, encapsulamiento, clases abstractas e interfaces.</li>
<li><strong>Programación Funcional</strong> - Streams, lambdas, Optionals, operaciones sobre colecciones.</li>
<li><strong>Maven</strong> - Gestión de dependencias, configuración y ejecución de tareas.</li>
<li><strong>Persistencia</strong> - JDBC con H2, JPA/Hibernate, ORM y consultas JPQL.</li>
<li><strong>Spring Framework</strong> - Spring Boot, Spring MVC, Spring Data JPA, arquitectura por capas (controllers, services, repositories).</li>
<li><strong>Arquitectura de Microservicios</strong> - API Gateway, comunicación entre servicios, Docker.</li>
<li><strong>Seguridad y OAuth 2.0</strong> - Keycloak embebido en contenedor Docker, autenticación y autorización con JWT, configuración para APIs.</li>
</ul>

<h2>Actividades principales</h2>

<ul>
<li><strong>Parciales resueltos</strong> - <code>basic-parcial-3k1</code> y <code>parcial-2k25</code> con soluciones comentadas.</li>
<li><strong>CRUDs con archivos y colecciones</strong> - Ejemplos de persistencia en CSV y uso de Map/HashMap.</li>
<li><strong>Introducción a JPA/Hibernate</strong> - Mapeo objeto-relacional y consultas JPQL.</li>
<li><strong>API REST con Spring Boot</strong> - Proyecto <code>spring-food</code> con endpoints, DTOs y lógica de negocio.</li>
<li><strong>Seguridad con Keycloak</strong> - Configuración de contenedor Docker, realms, clients, obtención de tokens JWT y validación en Postman.</li>
<li><strong>Scripts de automatización</strong> - <code>maven_init.py</code> para agilizar la creación de proyectos Maven.</li>
</ul>
